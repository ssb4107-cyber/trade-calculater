## 검증

- 계산·저장 자동 검증 9개: 시세 없음, 확정 손익, 소수 수량, 기존 자료 식별자, 빈 포트폴리오, 동시 저장, 저장 실패 후 재시도.
- 격리된 Edge 브라우저 검증 27개: 입력·수정·복제·새로고침, 지연 응답, 두 탭의 동시 추가·매도·수정·삭제, 중복 연결, 고정·수동 배치 유지, 저장 실패, 직접 파일 실행, 화면 크기 15종과 메뉴 펼침·접힘.
- 실제 API 키·시세 호출·개인 포트폴리오 데이터는 테스트에 사용하지 않는다.

```powershell
node --test tests/domain.test.cjs
# Playwright를 사용할 수 있는 환경에서 실행
node tests/portfolio.browser.cjs
# 특정 브라우저 검증만 실행할 때
$env:BROWSER_TEST_MATCH = "responsive"
node tests/portfolio.browser.cjs
```

브라우저 검증은 기본적으로 설치된 Edge를 사용한다. 다른 설치 채널은 `PLAYWRIGHT_CHANNEL`로 지정할 수 있다. Playwright를 프로젝트 밖에 설치한 경우 `NODE_PATH`에 해당 모듈 경로를 지정한다.

## 적용 범위와 남은 사항

저장 형식은 기존 `portfolioStocks` 배열을 유지한다. 로그인이나 추가 확인 절차를 요구하지 않는다. 같은 포지션 또는 거래의 같은 입력 항목을 두 탭에서 수정하면 나중에 저장한 입력값이 반영된다. 다른 포지션과 거래내역은 보존된다.

탭 간 동시 저장 보호는 Web Locks를 제공하는 브라우저에서 적용된다. 이번 검증은 Edge의 로컬 서버와 직접 파일 실행 환경에서 수행했다. Web Locks가 없는 환경에서는 최신 데이터 읽기와 현재 탭의 저장 순서 처리까지만 적용된다. 브라우저 저장소 삭제·다른 컴퓨터 간 동기화·구버전 화면의 저장은 별도 보호 대상이다. 적용 후 이미 열린 구버전 화면은 새로고침해야 한다.

기존에 저장된 잘못된 수량은 원래 입력값을 추정해 복구하지 않았다. F01의 기존 기본 API 키도 변경하거나 폐기하지 않았다.
